# 文档风格模板说明

> 场景：**简历 / CV**（内置场景模板）

## 页面

- A4；页边距 上/下/左/右 = 72 / 72 / 90 / 90 pt

## 字体

- 西文 Calibri，中文 微软雅黑；标题色 #2E74B5

## 段落样式

| 样式 | 字号 | 粗体 | 颜色 | 对齐 | 行距 |
|------|------|------|------|------|------|
| Heading1（姓名/主标题） | 22 | 是 | #2E74B5 | 居中 | - |
| Heading2（分节：教育/经历/技能） | 13 | 是 | #2E74B5 | 左 | - |
| Normal（条目正文） | 10.5 | - | - | 左 | 1.15 |

## 用法

把 page/theme/styles 合并进 document.json；分节用 `heading level=2`，条目用列表；日期右对齐（`align:"right"`）。
