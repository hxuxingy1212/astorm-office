# 排版设计规范（design-guide）

适用于所有文档。原则：**层级清晰、留白充足、单位统一、克制用色**。

## 1. 字号层级

| 角色 | 字号 | 样式 |
|------|------|------|
| 文档标题 Title | 22–28pt | 粗体、居中 |
| 副标题 Subtitle | 14–16pt | 常规/斜体、居中 |
| H1 | 18–20pt | 粗体 |
| H2 | 14–15pt | 粗体 |
| H3 | 12–13pt | 粗体 |
| 正文 | 11–12pt | 常规 |
| 题注 Caption | 10pt | 斜体、居中 |
| 脚注/页脚 | 9–10pt | 常规 |

同一页字号层级不超过 4 档；正文全文同一字体、字号。

## 2. 字体

- 学术：西文 Times New Roman，中文宋体，标题黑体。
- 商务：Calibri / 微软雅黑。
- 代码：Consolas / Courier New（`code` 块）。
- 中英混排必须显式设置中文字体，否则中文回退难看（模板已内置）。

## 3. 行距与间距

- 行距：正文 1.15–1.5 倍（学术常 1.5–2.0）。
- 段落间距用 `space_before` / `space_after`（标题前 12–18pt、后 6–12pt），**不要**用空段落堆叠。
- 正文首行缩进：中文学术 2 字符（≈24pt）；报告类通常不缩进。
- 页边距：常规上下 2.54cm、左右 3.17cm（约 72/90pt）。

## 4. 对齐

对齐由段落的 `align`（`left`/`center`/`right`/`justify`）与标题的 `align` 控制；不可依赖模板默认，**关键处须显式设置**：

- **文档标题 / 摘要标题**：居中（`heading.align = "center"` 或 `paragraph.align = "center"`）。
- **正文**：两端对齐（`align: "justify"`）；中文另加首行缩进 24pt。
- **章节/小节标题**：左对齐。
- **表格**：整表居中（`table.align = "center"`，默认），表头居中、文字左对齐、数字右对齐。
- **图片**：居中（`image.align = "center"`）。
- **落款 / 日期 / 签名**：右对齐（`align: "right"`）。

### 中文公文

- 标题居中；主送机关顶格（无缩进）；正文首行缩进 2 字符、两端对齐；
- 一级标题（一、二、三）可缩进；末尾落款与日期右对齐。

### 中文信函

- 称呼顶格；正文首行缩进 2 字符；
- “此致”空两格（`first_line_indent: 24`），“敬礼！”顶格；
- 署名与日期右对齐。

### 英文信函

- 日期右对齐；称呼、正文、落款均左对齐（块式，无首行缩进）。

## 5. 颜色

- 克制：正文黑色（默认），标题可用深色（`1F3864`）。
- 一套文档只用 1 个主色 + 1 个强调色；避免彩虹色。
- 深底浅字 / 浅底深字，保证对比度。
- 颜色 6 位十六进制**不带 `#`**（JSON 中）。

## 6. 版面均衡

- 一页一个核心信息；不要一页塞满。
- 元素成组、对齐、留白；任何元素不得溢出页面。
- 长文档保持一致的页眉/页脚与标题风格。

## 6.5 边框 / 方向

- 强调块用段落**盒式边框** `paragraph.border_box`（四边）+ `shading`，不要用表格冒充。
- 制表位对齐用 `paragraph.tabs`（`{pos,align,leader}`），前导符 `leader` 取 `dot`/`hyphen`。
- RTL（阿语/希伯来语）用 `paragraph.rtl`、`run.rtl`、`section.page.rtl`/`rtl_gutter`；脚本字体分别用 `font_family`/`east_asia_font`/`cs_font`。

## 7. 交付视觉核对

`render` 输出 HTML 后逐页确认：

- [ ] 标题层级在视觉上分明（大小/粗细）。
- [ ] 无占位符文本（`$x$`、`{{}}`、`<TODO>`、`lorem`）。
- [ ] 无截断/溢出的表格单元格。
- [ ] 图表题注在正确位置（图下/表上）。
- [ ] 公式渲染为数学形态而非纯文本。
- [ ] 页眉页脚、页码正常。
