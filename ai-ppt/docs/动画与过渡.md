# 动画与过渡

本文档介绍 `json2pptx` 支持的 **24 种元素动画**（含重复/重启/自动反向）与 **页面过渡（含 morph 变形）**，包括全部参数、触发逻辑与 OOXML 实现要点。

---

## 一、元素动画（Animation）

动画挂在元素的 `animations` 数组上：

```json
{
  "type": "text",
  "text": "标题",
  "position": { "x": 1, "y": 1, "w": 10, "h": 2 },
  "animations": [
    {
      "type": "flyIn",
      "duration": 500,
      "delay": 200,
      "trigger": "afterPrevious",
      "direction": "bottom",
      "order": 0
    }
  ]
}
```

所有基础元素（text / shape / image / table / group）与高级组件均支持 `animations`。

### 1.1 参数说明

| 字段 | 类型 | 默认 | 说明 |
|------|------|------|------|
| `type` | 字符串 | — | 动画类型（必填），24 种见下 |
| `duration` | 数字 | — | 持续时间（毫秒） |
| `delay` | 数字 | — | 触发延迟（毫秒） |
| `trigger` | 字符串 | — | 触发方式：`onClick` / `withPrevious` / `afterPrevious` |
| `direction` | 字符串 | — | 方向（对带方向的动画有效） |
| `order` | 数字 | — | 同页动画播放顺序 |
| `scale` | 数字 | — | 缩放目标比例（growShrink 用） |
| `degrees` | 数字 | — | 旋转角度（spin 用） |
| `color` | 字符串 | — | 目标颜色（colorChange 用） |
| `opacity` | 数字 | — | 目标透明度（transparency 用） |
| `points` | 数组 | — | 运动路径关键点（motionPath 用） |
| `distance` | 数字 | — | 运动路径距离（motionPath 用） |
| `repeat` | 字符串 | — | 重复次数（数字字符串或 `indefinite`） |
| `restart` | 字符串 | — | 重启方式（如 `whenNotActive`） |
| `auto_reverse` | 布尔 | — | 是否自动反向播放 |

### 1.2 24 种动画类型

| 类别 | 类型 | 说明 |
|------|------|------|
| **入场** | `appear` | 瞬间出现 |
| | `fadeIn` | 淡入 |
| | `flyIn` | 从指定方向飞入 |
| | `wipeIn` | 擦除式进入 |
| | `zoomIn` | 缩放进入 |
| | `bounceIn` | 弹跳进入 |
| | `floatIn` | 浮动进入（短距离移动） |
| | `swivel` | 旋转进入 |
| | `dissolveIn` | 溶解进入 |
| | `splitIn` | 分裂进入 |
| **退场** | `fadeOut` | 淡出 |
| | `flyOut` | 飞出 |
| | `wipeOut` | 擦除式退出 |
| | `zoomOut` | 缩放退出 |
| | `floatOut` | 浮动退出 |
| | `dissolveOut` | 溶解退出 |
| **强调** | `pulse` | 脉冲（放大再恢复） |
| | `spin` | 旋转（0° → `degrees`） |
| | `growShrink` | 缩放到 `scale` 指定比例 |
| | `colorChange` | 颜色变为 `color` |
| | `transparency` | 透明度变为 `opacity` |
| | `teeter` | 左右摇摆 |
| | `blink` | 闪烁 |
| **路径** | `motionPath` | 沿 `points` 自定义路径运动 |

### 1.3 触发方式（trigger）

| `trigger` | 效果 |
|-----------|------|
| `onClick` | 新起一个动画组，点击鼠标时触发 |
| `withPrevious` | 与上一个动画**同时**播放（归入同一组） |
| `afterPrevious` | 在上一个动画**结束后**播放（归入同一组） |

**分组逻辑**：`onClick` 触发新组；`withPrevious` / `afterPrevious` 并入当前组。同一组内的动画共享一个触发器，顺序由 `order` 决定。

### 1.4 方向（direction）

适用于 `flyIn`、`flyOut`、`wipeIn`、`wipeOut`、`splitIn` 等带方向的动画：

`top`（上）、`right`（右）、`bottom`（下）、`left`（左）、`topLeft`（左上）、`topRight`（右上）、`bottomLeft`（左下）、`bottomRight`（右下）

## 二、页面过渡（Transition）

过渡定义在幻灯片级别的 `transition` 字段，控制**页面切换**时的效果：

```json
{
  "background": "#1a1a2e",
  "transition": {
    "type": "fade",
    "speed": "med",
    "advance_on_click": true,
    "advance_after": 3000
  },
  "elements": []
}
```

### 2.1 参数说明

| 字段 | 类型 | 默认 | 说明 |
|------|------|------|------|
| `type` | 字符串 | — | 过渡类型（必填），见下 |
| `speed` | 字符串 | `med` | 速度：`slow` / `med` / `fast` |
| `advance_on_click` | 布尔 | `true` | 是否点击鼠标翻页 |
| `advance_after` | 数字 | — | 自动翻页延时（毫秒），如 `3000` = 3 秒后自动切换 |

### 2.2 过渡类型

| `type` | 说明 | OOXML 节点 |
|--------|------|-----------|
| `fade` | 淡入淡出 | `<p:fade/>` |
| `push` | 推入（新页把旧页推出） | `<p:push/>` |
| `wipe` | 擦除 | `<p:wipe/>` |
| `split` | 分裂（两半展开/收拢） | `<p:split/>` |
| `cover` | 覆盖（新页覆盖旧页） | `<p:cover/>` |
| `cut` | 直接切换 | `<p:cut/>` |
| `dissolve` | 溶解（旧页碎化消失） | `<p:dissolve/>` |
| `random` | 随机效果 | `<p:random/>` |
| `morph` | 平滑变形（PowerPoint 2010+） | `<p14:morph/>` |

> 解析真实 PPT 时，过渡类型直接取自过渡子元素的局部名（命名空间无关），因此 `p14:morph`、`p15:*` 等预设均能还原。

> 设计建议：正文演示优先使用 `fade` 或 `push`，避免使用 `random` 造成的杂乱感。

---

## 三、使用建议

| 场景 | 建议 |
|------|------|
| 标题入场 | `fadeIn` 或 `flyIn`，`trigger: "withPrevious"` |
| 正文逐条展示 | 每条 `flyIn` + `trigger: "afterPrevious"` |
| 强调某个数据 | `pulse` 或 `colorChange` |
| 退场提示 | `fadeOut` 或 `zoomOut` |
| 自动播放的展台 | 过渡用 `fade` + `advance_after: 3000` |
| 内容页动画 | 仅用入场动画，避免退场/强调动画分散注意力 |
