# 元素与组件参考

本文档详细介绍 `json2pptx` 支持的 **12 种基础元素**（文本、形状、线条、图片、表格、分组、图标、公式、真实图表、批注、公式(OMML)、不透明富对象）与 **10 种高级组件**（进度条、环形进度、柱状图、折线图、饼图、环形图、KPI 卡片、星级评分、时间线、流程步骤）的全部字段。

> 所有位置与尺寸单位为英寸；颜色为 6 位 hex（省略 `#`）或主题色别名（`accent1`、`dk1` 等，见 [JSON格式规范](JSON格式规范.md)）。

---

## 通用字段

以下字段适用于所有元素：

| 字段 | 类型 | 说明 |
|------|------|------|
| `type` | 字符串 | 元素类型（必填） |
| `position` | 对象 | `{ "x", "y", "w", "h" }`，单位英寸（必填） |
| `name` | 字符串 | 元素名称（显示在 PowerPoint 选择窗格中） |
| `animations` | 数组 | 动画列表，见 [动画与过渡](动画与过渡.md) |
| `placeholder` | 字符串 | 占位符引用 `"type|idx"`（解析自 `p:ph`，生成时回写，用于保留占位符语义） |
| `autofit` | 对象 | 文本自适应：`{ "kind": "none"/"shape"/"normal", "font_scale"?, "ln_spc_reduction"? }`（文本/形状） |
| `effects` | 对象 | 附加效果：`{ "glow", "reflection", "soft_edge", "blur", "inner_shadow", "fill_overlay" }`（文本/形状） |

`position` 的四个分量均为必填：`x`（距左上角水平偏移）、`y`（距左上角垂直偏移）、`w`（宽度）、`h`（高度）。

## 1. 文本元素（text）

文本框，支持多段落、多 run、换行、项目符号与中英文混排。

```json
{
  "type": "text",
  "text": "你好，世界",
  "position": { "x": 1, "y": 1, "w": 10, "h": 2 },
  "font_size": 48,
  "bold": true,
  "italic": false,
  "underline": false,
  "color": "FFFFFF",
  "font_family": "Noto Sans SC",
  "align": "center",
  "vert_align": "middle",
  "wrap": false,
  "fill": "4472C4",
  "fill_alpha": 0.5,
  "line": { "color": "000000", "width": 1.5 },
  "line_alpha": 0.8,
  "shadow": { "blur": 6, "distance": 3, "angle": 45, "opacity": 0.5, "color": "000000" },
  "animations": []
}
```

| 字段 | 类型 | 说明 |
|------|------|------|
| `text` | 字符串 / 数组 | 内容。字符串为纯文本（`"你好"`）；数组为多段落结构（`[...]`，见下） |
| `font_size` | 数字 | 字号（点） |
| `bold` / `italic` / `underline` | 布尔 | 字形 |
| `color` | 字符串 | 文字颜色 |
| `font_family` | 字符串 | 字体。**同时作用于拉丁（`<a:latin>`）、东亚（`<a:ea>`）与复杂文字（`<a:cs>`）三种字体槽**，中文文本必须设置（如 `"Microsoft YaHei"`） |
| `align` | 字符串 | 水平对齐：`left` / `center` / `right` / `justify` |
| `vert_align` | 字符串 | 垂直对齐：`top` / `middle` / `bottom` |
| `wrap` | 布尔 | 是否自动换行，`false` 为不换行 |
| `fill` | 字符串 / 对象 | 文本框背景：纯色字符串 `"hex"` 或渐变 `{"stops":[...],"angle":...}`（见下方形状填充说明） |
| `fill_alpha` | 数字 | 背景透明度（0.0–1.0） |
| `line` | 对象 | 边框：`{ "color", "width" }`，宽度单位点 |
| `line_alpha` | 数字 | 边框透明度（0.0–1.0） |
| `shadow` | 对象 | 阴影：`{ "blur", "distance", "angle", "opacity", "color" }` |
| `animations` | 数组 | 动画列表 |

### 多段落 / 多 run 写法

```json
{
  "type": "text",
  "text": [
    {
      "runs": [
        { "text": "加粗红字 ", "bold": true, "color": "FF0000" },
        { "text": "斜体", "italic": true }
      ],
      "align": "center",
      "bullet": true
    },
    {
      "text": "普通段落",
      "align": "left"
    }
  ]
}
```

每个段落包含 `runs`（run 数组）、`text`（单 run 简写）、`align`、`bullet`（项目符号）、`line_spacing`（行距：正值为倍数、负值为固定磅数）。

每个 run 支持：`text` / `font_size` / `bold` / `italic` / `underline` / `color` / `font_family` / `hyperlink` / `highlight`（高亮底色）/ `underline_color`（下划线颜色）/ `spacing`（字距，磅）/ `lang`（语言标签，如 `zh-CN`）/ `rtl`（从右到左）。

### 文本超链接

run 级 `hyperlink` 字段可为文字添加网页超链接（生成 `<a:hlinkClick>`）：

```json
{
  "type": "text",
  "text": [
    { "runs": [
        { "text": "点击访问官网 ", "color": "0563C1", "underline": true, "hyperlink": "https://example.com" },
        { "text": "普通文字" }
    ]}
  ],
  "position": { "x": 1, "y": 1, "w": 6, "h": 1 }
}
```

### 换行

- 简单字符串中直接写 `\n`，生成时转换为 `<a:br/>`，解析时合并回 `\n`（回环保留）。

## 2. 形状元素（shape）

86 种预设形状（基础图形、箭头、流程符号、标注等），支持填充、线条、阴影、旋转与 adjust 调整值。

```json
{
  "type": "shape",
  "shape_type": "roundRect",
  "position": { "x": 1, "y": 1, "w": 4, "h": 3 },
  "rotation": 30,
  "fill": "ED7D31",
  "fill_alpha": 0.3,
  "no_fill": false,
  "line": { "color": "000000", "width": 1 },
  "line_alpha": 0.5,
  "shadow": { "blur": 8, "distance": 4, "angle": 135, "opacity": 0.6, "color": "000000" },
  "adjust": { "adj": 15000 },
  "text": "内部文字",
  "font_size": 18,
  "color": "FFFFFF",
  "align": "center",
  "animations": []
}
```

| 字段 | 类型 | 说明 |
|------|------|------|
| `shape_type` | 字符串 | 形状类型（必填），86 种见下 |
| `rotation` | 数字 | 旋转角度（度） |
| `fill` | 字符串 / 对象 | 填充（untagged）：纯色字符串 `"ED7D31"` / 渐变 `{"stops":[{"color","position"}],"angle"}` / 图案 `{"pattern","fg","bg"}` / 图片填充 `{"src"}` |
| `fill_alpha` | 数字 | 填充透明度（0.0–1.0，默认 1.0） |
| `no_fill` | 布尔 | `true` 时不填充（只留边框），优先级高于 `fill` |
| `line` | 对象 | 边框 `{ "color", "width" }`，默认线端为平角（cap=flat） |
| `line_alpha` | 数字 | 边框透明度（0.0–1.0，默认 1.0） |
| `shadow` | 对象 | 阴影（同文本元素） |
| `effects` | 对象 | 附加效果：`glow`（`{color,radius,opacity}`）/ `reflection`（bool）/ `soft_edge`（半径磅）/ `blur`（半径磅）/ `inner_shadow`（同 shadow）/ `fill_overlay`（`{color,opacity}`） |
| `autofit` | 对象 | 文本自适应（`kind`/`font_scale`/`ln_spc_reduction`） |
| `adjust` | 对象 | 形状调整值，如圆角矩形 `{"adj": 15000}` 控制圆角半径 |
| `text` | 字符串 / 对象 | 形状内部文字（可选） |
| `font_size` / `color` / `align` | — | 仅作用于内部文字 |

> 解析真实 PPT 时，形状的填充/线条还可能来自 `<p:style>` 的 `fillRef`/`lnRef`，解析端会将其作为缺省回退；若同时存在显式 `no_fill`，以显式为准。

### 渐变填充写法

```json
"fill": {
  "stops": [
    { "color": "1A365D", "position": 0.0 },
    { "color": "0B1D3A", "position": 1.0 }
  ],
  "angle": 135
}
```

`stops` 的 `position` 为 0.0–1.0 的归一化位置（0 为起点、1 为终点），`angle` 为角度（度）。
填充为 **untagged** 编码：纯色直接写字符串 `"ED7D31"`；渐变写含 `stops` 的对象；图案写 `{"pattern","fg","bg"}`；图片写 `{"src"}`。

## 3. 线条元素（line）

独立的线条元素（直线 / 折线 / 曲线），支持箭头端点与虚线样式。生成时输出为 OOXML 连接线（`<p:cxnSp>` + `<a:custGeom>`）。

```json
{
  "type": "line",
  "position": { "x": 1, "y": 2, "w": 5, "h": 0.5 },
  "name": "箭头线",
  "points": [[0, 0.25], [5, 0.25]],
  "color": "E74C3C",
  "width": 2.5,
  "dash": "dashed",
  "arrow_start": "none",
  "arrow_end": "arrow",
  "smooth": false,
  "rotation": 0,
  "animations": []
}
```

| 字段 | 类型 | 说明 |
|------|------|------|
| `points` | 数组 | 顶点列表（必填，至少 2 个点），坐标为**相对 position 原点**的英寸；两点为直线，多点折线 |
| `color` | 字符串 | 线条颜色（默认主题强调色） |
| `width` | 数字 | 线条宽度（点，默认 1.0） |
| `dash` | 字符串 | 虚线样式：`solid` / `dashed` / `dotted` |
| `arrow_start` | 字符串 | 起点端点：`none` / `arrow`（箭头）/ `dot`（圆点） |
| `arrow_end` | 字符串 | 终点端点：同上 |
| `smooth` | 布尔 | `true` 时相邻顶点间用二次贝塞尔连接（曲线） |
| `rotation` | 数字 | 旋转角度（度） |

> **注意**：`points` 为空时缺省为从左上到右下的对角线。线条不支持内部文字。

## 4. 图片元素（image）

```json
{
  "type": "image",
  "src": "./assets/logo.png",
  "position": { "x": 0.5, "y": 0.5, "w": 5, "h": 4 },
  "rotation": 15,
  "crop": { "left": 10, "top": 20, "right": 30, "bottom": 40 },
  "hyperlink": "https://example.com",
  "line": { "color": "FF0000", "width": 3 },
  "animations": []
}
```

| 字段 | 类型 | 说明 |
|------|------|------|
| `src` | 字符串 | 图片路径（必填）：本地相对/绝对路径，或 HTTP(S) URL（生成时自动下载） |
| `rotation` | 数字 | 旋转角度（度） |
| `crop` | 对象 | 裁剪（百分比 0–100）：`{ "left", "top", "right", "bottom" }` |
| `hyperlink` | 字符串 | 点击图片跳转的 URL |
| `line` | 对象 | 图片边框 `{ "color", "width" }` |
| `brightness` / `contrast` | 数字 | 亮度 / 对比度调整（-1.0 ~ 1.0，对应 `<a:lum>`） |
| `fill_mode` | 字符串 | `stretch`（默认）/ `tile`（平铺） |
| `tooltip` | 字符串 | 悬浮提示（`descr` / 超链接 tooltip） |
| `media` | 对象 | 关联视频/音频：`{ "kind": "video"/"audio", "src": "…" }`（图片作为封面） |
| `animations` | 数组 | 动画列表 |

**生成行为**：

1. `src` 的图片字节被复制到 PPTX 内部 `ppt/media/imageN.*`（按顺序编号，扩展名保持原样）；
2. 在幻灯片关系文件（`.rels`）中建立 rId → 图片映射；
3. 在 `[Content_Types].xml` 中注册图片 MIME 类型。

> 支持 `png` / `jpg` / `gif` / `svg` / `webp` 等格式；`unpack` 可把 PPTX 内嵌图片提取到产物 `ppt/media/` 目录，JSON 中以绝对路径引用。

## 5. 表格元素（table）

```json
{
  "type": "table",
  "position": { "x": 0.5, "y": 0.5, "w": 9, "h": 3 },
  "header_row": true,
  "column_widths": [3.0, 2.0, 4.0],
  "rows": [
    [
      { "text": "姓名", "bold": true, "fill": "4472C4", "color": "FFFFFF", "align": "center" },
      { "text": "数值", "bold": true, "fill": "4472C4", "color": "FFFFFF" }
    ],
    [
      { "text": "Alpha" },
      { "text": "42", "bold": true, "align": "right" }
    ]
  ],
  "font_size": 12,
  "color": "333333",
  "animations": []
}
```

| 字段 | 类型 | 说明 |
|------|------|------|
| `header_row` | 布尔 | 首行启用表头特殊样式（自动加粗） |
| `rows` | 数组 | 行数组，每行是单元格数组（必填）；按"逻辑网格"书写（见下方合并单元格） |
| `column_widths` | 数组 | 每列宽度（英寸），缺省均分表格总宽；长度 = 物理列数 |
| `row_heights` | 数组 | 各行高度（英寸），缺省按表格总高均分（解析自 `<a:tr h>`） |
| `style_id` | 字符串 | 内置表格样式 GUID（解析自 `<a:tblStyle val>` / `<a:tableStyleId>`） |
| `rtl` | 布尔 | 从右到左 |
| `tbl_attrs` | 字符串 | 原始 `a:tblPr` 属性（`firstRow`/`bandRow`/`firstCol`… 解析保留，生成时原样回写） |
| `font_size` | 数字 | 整表默认字号，单元格级可覆盖 |
| `color` | 字符串 | 整表默认文字颜色，单元格级可覆盖 |
| `animations` | 数组 | 动画列表 |

### 单元格（Cell）字段

| 字段 | 类型 | 说明 |
|------|------|------|
| `text` | 字符串 | 单元格文字 |
| `font_size` | 数字 | 覆盖整表字号 |
| `bold` | 布尔 | 粗体 |
| `color` | 字符串 | 覆盖整表颜色 |
| `fill` | 字符串 | 单元格背景色 |
| `align` | 字符串 | 对齐：`left` / `center` / `right` |
| `colspan` | 数字 | 横向合并的列数（默认 1） |
| `rowspan` | 数字 | 纵向合并的行数（默认 1） |
| `border` | 对象 | 四边同色同宽边框 `{ "color", "width" }`（解析自 `lnL/lnR/lnT/lnB`） |
| `margin` | 数组 | 单元格内边距 `[left, top, right, bottom]`（英寸，解析自 `marL/marT/marR/marB`） |
| `vert` | 字符串 | 文字方向：`vert`（竖排） |
| `anchor` | 字符串 | 单元格垂直对齐：`t`（默认）/ `ctr` / `b` |
| `fill_image` | 字符串 | 单元格图片填充路径（解析自 `tcPr/blipFill`） |

> 若 `header_row: true`，第一行单元格即使未显式写 `"bold": true` 也会自动加粗。

### 合并单元格

表格按**逻辑网格**书写：合并主格只出现一次，被合并的列 / 行位置不写（生成时自动补 OOXML 占位格，解析时合并回主格）：

```json
{
  "type": "table",
  "position": { "x": 0.5, "y": 0.5, "w": 6, "h": 2 },
  "column_widths": [2.0, 2.0, 2.0],
  "rows": [
    [ { "text": "合并标题", "colspan": 3 } ],
    [ { "text": "A", "rowspan": 2 }, { "text": "B" }, { "text": "C" } ],
    [ { "text": "D" }, { "text": "E" } ]
  ]
}
```

上例 3 列物理网格：第一行标题横跨全部 3 列；第二行 `A` 纵向合并 2 行，第三行 `D`/`E` 位于被覆盖列之后的空位。

## 6. 分组元素（group）

```json
{
  "type": "group",
  "position": { "x": 0.5, "y": 0.5, "w": 9, "h": 4 },
  "rotation": 10,
  "children": [
    { "type": "text", "text": "分组文本", "position": { "x": 0, "y": 0, "w": 5, "h": 1 } },
    { "type": "shape", "shape_type": "rect", "fill": "00FF00", "position": { "x": 0, "y": 1.5, "w": 3, "h": 2 } }
  ],
  "animations": []
}
```

| 字段 | 类型 | 说明 |
|------|------|------|
| `children` | 数组 | 子元素列表（必填），支持任意嵌套 |
| `rotation` | 数字 | 组级旋转，所有子元素跟随 |
| `position` | 对象 | 组合容器位置，子元素坐标相对此容器 |
| `animations` | 数组 | 动画列表 |

## 7. 解析产出元素（chart / comment / equation / opaque）

以下类型主要由 `unpack` / `parse` 从真实 PPTX 中还原，用于保留数据与结构（部分也支持手写生成）。它们出现在 `elements` 中，可被 `view` / `edit` / `query` 寻址。

### 7.1 chart（真实图表）

```json
{
  "type": "chart",
  "position": { "x": 2.5, "y": 1.2, "w": 5, "h": 3 },
  "chart_type": "line",
  "title": "季度营收",
  "categories": ["Q1", "Q2", "Q3"],
  "series": [ { "name": "2024", "values": [10, 20.5, 15], "color": "4472C4" } ],
  "legend": true,
  "legend_position": "bottom",
  "raw": "<c:chartSpace>…</c:chartSpace>"
}
```

- 解析自 `ppt/charts/chartN.xml`（或任意 `/charts/` 目录）。`chart_type`：`column`/`bar`/`line`/`pie`/`doughnut`/`area`/`scatter`/`bubble`/`stock`/`radar`/`surface`
- `raw` 保存**原始图表部件 XML**（已剥离 `c:externalData`），生成时优先原样回写以保留全部样式；其余结构化字段供查询与编辑

### 7.2 comment（批注）

```json
{ "type": "comment", "position": { "x": 2, "y": 3, "w": 0, "h": 0 }, "author": "审阅者", "text": "请修改" }
```

解析自 `ppt/comments/commentN.xml` + `commentAuthors.xml`。

### 7.3 equation（Office 公式，OMML）

```json
{ "type": "equation", "position": { "x": 2, "y": 3, "w": 4, "h": 1 }, "omml": "<a14:m>…</a14:m>", "text": "x=1" }
```

`omml` 保存原始 OMML 子树（解析自 `a14:m` / `m:oMath`），生成时内嵌回文本框；`text` 为提取的近似文本。

### 7.4 opaque（不透明富对象）

```json
{ "type": "opaque", "position": { "x": 1, "y": 1, "w": 5, "h": 3 }, "xml": "<p:graphicFrame>…</p:graphicFrame>" }
```

用于 OLE 对象、SmartArt、3D（`.glb`）、slide zoom 等无法完整建模的引用型对象：保存**原始元素 XML + 关系 + 传递闭包部件**（`rels`/`parts`），生成时原样回写，保证回环不丢数据。

## 8. 高级组件（Components）

高级组件生成时自动**展开**为多个基础形状的 Group。展开后组件类型信息不再保留——把生成的 PPTX 解析回 JSON 时，组件会变成普通 `group`。

### 8.1 progressBar（水平进度条）

```json
{
  "type": "progress_bar",
  "position": { "x": 0.5, "y": 0.3, "w": 9, "h": 0.6 },
  "value": 75,
  "color": "4472C4",
  "track_color": "E0E0E0",
  "rounded": true,
  "show_label": true,
  "label": "进度",
  "text_color": "000000",
  "font_size": 11
}
```

| 字段 | 类型 | 说明 |
|------|------|------|
| `value` | 数字 | 进度值 0–100（必填） |
| `color` | 字符串 | 进度条颜色 |
| `track_color` | 字符串 | 轨道（背景条）颜色 |
| `rounded` | 布尔 | 是否圆角 |
| `show_label` | 布尔 | 是否显示标签 |
| `label` | 字符串 | 自定义标签文字（缺省显示 `"75%"`） |
| `text_color` | 字符串 | 标签文字颜色 |
| `font_size` | 数字 | 标签字号 |

展开为 2～3 个形状：轨道（roundRect/rect）→ 进度填充（宽度 = value%）→ 可选标签。

### 8.2 progressRing（环形进度指示器）

```json
{
  "type": "progress_ring",
  "position": { "x": 0.5, "y": 1.2, "w": 1.5, "h": 1.5 },
  "value": 60,
  "color": "ED7D31",
  "track_color": "E0E0E0",
  "thickness": 8,
  "show_label": true,
  "text_color": "333333",
  "font_size": 14
}
```

| 字段 | 类型 | 说明 |
|------|------|------|
| `value` | 数字 | 进度值 0–100（必填） |
| `color` | 字符串 | 进度弧颜色 |
| `track_color` | 字符串 | 轨道环颜色 |
| `thickness` | 数字 | 环的粗细（点） |
| `show_label` | 布尔 | 是否显示中心百分比 |
| `text_color` / `font_size` | — | 中心文字样式 |

展开为 2～3 个形状：轨道空环（ellipse + 线框）→ 彩色弧段（blockArc，弧长 = value%）→ 中心百分比标签。

### 8.3 barChart（柱状图）

```json
{
  "type": "bar_chart",
  "position": { "x": 2.5, "y": 1.2, "w": 4, "h": 1.5 },
  "data": [30, 50, 80, 40],
  "labels": ["Q1", "Q2", "Q3", "Q4"],
  "colors": ["FF0000", "00FF00", "0000FF", "FFAA00"],
  "max": 100,
  "show_values": true,
  "axis": true,
  "label_color": "333333",
  "font_size": 10
}
```

| 字段 | 类型 | 说明 |
|------|------|------|
| `data` | 数组 | 数据值数组（必填），每个值一根柱 |
| `labels` | 数组 | 底部标签数组（与 `data` 等长） |
| `colors` | 数组 | 每根柱的颜色数组 |
| `max` | 数字 | 纵轴最大值（用于计算柱高比例，缺省取数据最大值） |
| `show_values` | 布尔 | 柱顶显示数值 |
| `axis` | 布尔 | 显示坐标轴 |
| `label_color` / `font_size` | — | 标签样式 |

> **注意**：这不是真正的 Excel 图表对象，而是用矩形形状模拟的柱状图。

### 8.4 lineChart（折线图）

```json
{
  "type": "line_chart",
  "position": { "x": 2.5, "y": 1.2, "w": 4, "h": 1.5 },
  "data": [12, 25, 18, 30],
  "labels": ["Q1", "Q2", "Q3", "Q4"],
  "colors": ["4472C4"],
  "max": 40,
  "show_values": true,
  "axis": true,
  "smooth": false,
  "label_color": "333333",
  "font_size": 10
}
```

| 字段 | 类型 | 说明 |
|------|------|------|
| `data` | 数组 | 数据值数组（必填），每个值一个数据点 |
| `labels` | 数组 | 底部标签数组（与 `data` 等长） |
| `colors` | 数组 | 折线与数据点颜色（取第一项，缺省主题蓝） |
| `max` | 数字 | 纵轴最大值（缺省取数据最大值） |
| `show_values` | 布尔 | 数据点上方显示数值 |
| `axis` | 布尔 | 显示坐标轴 |
| `smooth` | 布尔 | `true` 时折线用二次贝塞尔平滑 |
| `label_color` / `font_size` | — | 标签样式 |

> 用连接线 + 椭圆数据点模拟，非 Excel 图表对象。

### 8.5 pieChart（饼图）

```json
{
  "type": "pie_chart",
  "position": { "x": 2.5, "y": 3, "w": 3, "h": 3 },
  "data": [30, 50, 20],
  "labels": ["A", "B", "C"],
  "colors": ["E74C3C", "F1C40F", "2ECC71"],
  "show_values": true,
  "label_color": "333333",
  "font_size": 10
}
```

| 字段 | 类型 | 说明 |
|------|------|------|
| `data` | 数组 | 数据值数组（必填），每个值一个扇区，按比例切分 360° |
| `labels` | 数组 | 图例标签数组（显示在图表下方） |
| `colors` | 数组 | 每个扇区的颜色（缺省取内置 8 色） |
| `show_values` | 布尔 | 扇区外侧显示百分比 |
| `label_color` / `font_size` | — | 标签样式 |

> 用 `pie` 预设形状（旋转 + adj 扇区角）模拟，从 12 点方向顺时针排列，非 Excel 图表对象。

### 8.6 ringChart（环形图）

```json
{
  "type": "ring_chart",
  "position": { "x": 6.5, "y": 3, "w": 3, "h": 3 },
  "data": [60, 40],
  "labels": ["A", "B"],
  "colors": ["4472C4", "ED7D31"],
  "thickness": 0.35,
  "show_values": true,
  "label_color": "333333",
  "font_size": 10
}
```

| 字段 | 类型 | 说明 |
|------|------|------|
| `data` | 数组 | 数据值数组（必填），每个值一个环段 |
| `labels` | 数组 | 图例标签数组 |
| `colors` | 数组 | 每个环段的颜色 |
| `thickness` | 数字 | 环宽占半径比例（0–1，缺省 0.35；环宽为 `blockArc` 形状固有比例） |
| `show_values` | 布尔 | 环段外侧显示百分比 |
| `label_color` / `font_size` | — | 标签样式 |

> 用 `blockArc` 预设形状模拟（浅色 track 整环 + 各环段），超过 180° 的段自动拆为两段，非 Excel 图表对象。

### 8.7 kpiCard（KPI 卡片）

```json
{
  "type": "kpi_card",
  "position": { "x": 7, "y": 1.2, "w": 2.5, "h": 1.5 },
  "value": "98.5%",
  "label": "满意度",
  "delta": "+5.2%",
  "bg": "FFFFFF",
  "accent": "00AA00",
  "rounded": true,
  "text_color": "333333"
}
```

| 字段 | 类型 | 说明 |
|------|------|------|
| `value` | 字符串 | 主数值（必填），以大号粗体显示 |
| `label` | 字符串 | 小标题 |
| `delta` | 字符串 | 变化指示（正数绿色 / 负数红色） |
| `bg` | 字符串 | 卡片背景色 |
| `accent` | 字符串 | 强调条颜色（底部细条） |
| `rounded` | 布尔 | 卡片圆角 |
| `text_color` | 字符串 | 文字颜色 |

展开为 3～4 个形状：卡片背景 → 强调条 → 大号数值 → 标签（+ 可选 Delta）。

### 8.8 ratingStars（星级评分）

```json
{
  "type": "rating_stars",
  "position": { "x": 0.5, "y": 3, "w": 3, "h": 0.6 },
  "rating": 4.5,
  "max": 5,
  "color": "FFAA00",
  "empty_color": "E0E0E0"
}
```

| 字段 | 类型 | 说明 |
|------|------|------|
| `rating` | 数字 | 评分值（必填） |
| `max` | 数字 | 星星总数（默认 5） |
| `color` | 字符串 | 已点亮星星颜色 |
| `empty_color` | 字符串 | 未点亮星星颜色 |

展开为 N 个五角星（`star5`）：`i < rating` 的用 `color`，其余用 `empty_color`。

### 8.9 timeline（水平时间线）

```json
{
  "type": "timeline",
  "position": { "x": 0.5, "y": 3.8, "w": 9, "h": 1 },
  "items": [
    { "date": "2024-Q1", "title": "阶段一", "desc": "调研" },
    { "date": "2024-Q2", "title": "阶段二", "desc": "开发" }
  ],
  "line_color": "4472C4",
  "dot_color": "ED7D31",
  "label_color": "333333"
}
```

| 字段 | 类型 | 说明 |
|------|------|------|
| `items` | 数组 | 时间节点数组（必填），每项为对象（`date` / `title` / `desc` 等，会拼成标签文字） |
| `line_color` | 字符串 | 基线的颜色 |
| `dot_color` | 字符串 | 圆点颜色 |
| `label_color` | 字符串 | 标签文字颜色 |

展开为 1 + N×2 个形状：水平基线 → 每节点一个圆点（ellipse）+ 一个标签文本框。

### 8.10 processFlow（流程步骤）

```json
{
  "type": "process_flow",
  "position": { "x": 0.5, "y": 5, "w": 9, "h": 0.6 },
  "steps": ["计划", "执行", "检查", "改进"],
  "colors": ["4472C4", "ED7D31", "70AD47", "FF0000"],
  "text_color": "FFFFFF",
  "font_size": 12
}
```

| 字段 | 类型 | 说明 |
|------|------|------|
| `steps` | 数组 | 步骤名称数组（必填） |
| `colors` | 数组 | 每步的圆角矩形颜色 |
| `text_color` / `font_size` | — | 步骤文字样式 |

展开为 N + (N-1) 个形状：每步一个 roundRect + 步骤间一个右箭头（`rightArrow`，颜色 `95a5a6`）。

## 9. 幻灯片级字段

除元素外，每张幻灯片还支持：

| 字段 | 类型 | 说明 |
|------|------|------|
| `notes` | 字符串 | **演讲者备注**（纯文本，多行用 `\n`）。生成时输出为 OOXML `notesSlide` 部件（含 notesMaster），PowerPoint / WPS 的"备注"窗格可见；解析时自动还原 |
| `background` | 字符串 / 对象 | 背景：纯色 / 渐变 / 图片 |
| `transition` | 对象 | 幻灯片过渡动画，见 [动画与过渡](动画与过渡.md) |

```json
{
  "notes": "第一页要点\n- 方案 A\n- 方案 B",
  "background": "#1a1a2e",
  "elements": []
}
```
