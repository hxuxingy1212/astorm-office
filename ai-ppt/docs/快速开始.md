# 快速开始

本文档带你从零开始使用 `json2pptx`，包括环境准备、安装构建、命令行使用、库调用方式与一个完整示例。

> 完整的 JSON 格式说明见 [JSON格式规范](JSON格式规范.md)，命令行细节见 [命令行工具](命令行工具.md)。

---

## 环境要求

| 依赖 | 版本要求 |
|------|---------|
| Rust 工具链 | 1.75+（含 `cargo`） |
| 操作系统 | macOS / Linux / Windows 均可 |

项目无任何 MS Office、PowerPoint 或 PPTX SDK 运行时依赖，生成与解析 OOXML 全部由纯 Rust 实现。

---

## 安装与构建

### 获取源码并构建

```bash
git clone <仓库地址>
cd json2pptx
cargo build --release
```

构建产物为：

- 库 `json2pptx`（Rust crate）
- 可执行文件 `json2pptx`（位于 `target/release/json2pptx`）

### 全局安装 CLI

```bash
cargo install --path cli
json2pptx unpack in.pptx -o out/
```

安装后可直接使用 `json2pptx` 命令（下文示例以 `json2pptx` 或 `cargo run --bin json2pptx --` 两种形式给出，效果相同）。

---

## 使用命令行：PPTX → 可编辑中间产物

```bash
# 解包：按幻灯片拆分为 JSON + 媒体目录
json2pptx unpack input.pptx -o out/
```

产物结构：

```
out/
├── presentation.json           # 顶层（meta/theme/尺寸），slides 为文件路径数组
└── ppt/
    ├── slides/slide1.json      # 每张幻灯片一个 JSON（可直接编辑）
    └── media/image1.png        # 媒体文件实体（保留包内路径）
```

---

## 使用命令行：查看与精准修改

```bash
# 查看某页文本与媒体（媒体为绝对路径）
json2pptx view input.pptx /slide[1] text

# 查看某页组件布局（树形）
json2pptx view input.pptx /slide[1] layout

# 精准修改：一次性修改并输出新文件（原文件不变）
json2pptx edit input.pptx /slide[1]/text[1] set --prop text=新标题 -o new.pptx
json2pptx edit input.pptx /slide[1] add --type text --prop text=正文 --prop x=1 --prop y=2 --prop w=8 --prop h=2 -o new.pptx
json2pptx edit input.pptx /slide[1]/shape[2] remove -o new.pptx

# 多次修改：直接操作产物目录（原地修改），最后 repack
json2pptx edit out/ /slide[1]/text[1] set --prop text=新标题
json2pptx repack out/ -o output.pptx
```

## 使用命令行：重建 PPTX

```bash
# 从产物重建（产物目录由 unpack 显式创建）
json2pptx repack out/ -o output.pptx
```

> 模板：产物 `presentation.json` 的 `template` 字段支持 6 种预设（`modern` / `dark` / `corporate` / `creative` / `nature` / `minimal`），详见 [模板系统](模板系统.md)。可用 `json2pptx templates` 查看列表。

## 其他常用命令

```bash
# 渲染某页为 PNG（输入可为 .pptx 或产物目录）
json2pptx render input.pptx /slide[1] -o slide1.png

# 打印 JSON Schema 说明指引
json2pptx schema

# 列出全部 6 种模板预设
json2pptx templates
```

完整的命令参数说明见 [命令行工具](命令行工具.md)。

## 在 Rust 代码中使用库

### 添加依赖

```toml
[dependencies]
json2pptx = { git = "<仓库地址>" }
serde_json = "1"
```

### 编写代码

```rust
use json2pptx::model::*;
use json2pptx::model::elements::*;
use json2pptx::generate;

fn main() -> Result<(), Box<dyn std::error::Error>> {
    // 构建 Presentation 模型（字段与 JSON 一一对应）
    let pres = Presentation {
        width: 13.333,
        height: 7.5,
        meta: Some(Meta {
            title: Some("你好".to_string()),
            author: Some("json2pptx".to_string()),
        }),
        theme: Some(Theme {
            colors: Some(std::collections::HashMap::from([
                ("accent1".to_string(), "4472C4".to_string()),
            ])),
            major_font: Some("Calibri Light".to_string()),
            minor_font: Some("Calibri".to_string()),
        }),
        slides: vec![Slide {
            background: Some(serde_json::json!("#1a1a2e")),
            transition: None,
            elements: vec![
                Element::Text(TextElement {
                    text: TextContent::Simple("你好，PowerPoint！".to_string()),
                    position: Position { x: 1.0, y: 2.0, w: 10.0, h: 2.0 },
                    font_size: Some(48.0),
                    bold: Some(true),
                    color: Some("FFFFFF".to_string()),
                    align: Some("center".to_string()),
                    font_family: Some("Noto Sans SC".to_string()),
                    ..Default::default()
                }),
            ],
        }],
    };

    // 生成 PPTX 文件
    let result = generate(&pres, "output.pptx")?;
    println!("已生成: {} ({} 页)", result.path, result.slides);
    Ok(())
}
```

库的三大公共 API：

| API | 功能 |
|-----|------|
| `json2pptx::generate(&model, path)` | JSON 模型 → PPTX 文件 |
| `json2pptx::parse(path)` | PPTX 文件 → JSON 模型 |
| `json2pptx::parse::extract_media(&mut model, pptx_path, dir)` | 提取 PPTX 内嵌媒体并修正路径 |

> 解析得到的模型可直接用 `serde_json::to_string_pretty` 序列化为 JSON。

## 验证生成结果

生成的 `.pptx` 可用任意支持 PowerPoint 的软件打开（WPS、LibreOffice、Microsoft PowerPoint 均可）。

`json2pptx` 保证 JSON → PPTX → JSON 的**回环一致性**：解析自己生成的 PPTX 应得到与输入等价的 JSON（动画、背景、元素、过渡均保留）。仓库内置 39 个集成测试（回环 / unpack-repack / CLI），运行方式：

```bash
cargo test
```

## 常见问题

| 问题 | 解决方案 |
|------|---------|
| 生成的 PPTX 中文显示为方块 | 元素上设置 `font_family`（如 `"Microsoft YaHei"`），或使用带中文字体的模板（如 `--template dark`，次要字体为 Noto Sans SC） |
| 图片路径无法加载 | `src` 支持相对/绝对本地路径与 HTTP(S) URL；URL 会在生成时自动下载嵌入 |
| 需要提取他人 PPTX 中的图片 | `unpack in.pptx -o out/`，媒体落在 `out/ppt/media/`（绝对路径引用） |
| 希望快速得到一份可编辑的 JSON 起点 | `unpack in.pptx -o out/`，编辑 `out/ppt/slides/*.json` |
| 需要逐页编辑他人 PPTX 的内容 | `unpack in.pptx -o out/` → 编辑 `out/ppt/slides/*.json` → `repack out/ -o new.pptx` |
| 快速查看某页的文本与媒体（含绝对路径） | `view in.pptx /slide[1] text` |
| 精准修改某页元素（改字/增删元素） | `edit in.pptx /slide[1]/text[1] set --prop text=新标题`，随后 `repack` |
| 想知道 JSON 中某个字段最终生成了什么 XML | 查阅 [OOXML映射参考](OOXML映射参考.md) |
