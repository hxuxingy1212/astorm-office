# 模板系统

`json2pptx` 内置 **6 种模板预设**，每种包含完整的 12 色配色方案、标题/正文字体与默认背景色。模板在生成时自动合并到主题中，无需在 JSON 中重复填写颜色和字体。

---

## 1. 模板总览

| 名称 | 显示名 | 描述 | 默认背景 | 标题字体 | 正文字体 |
|------|--------|------|---------|---------|---------|
| `modern` | 现代简洁 | Clean blue & white（清爽蓝白） | `#FFFFFF` | Segoe UI | Microsoft YaHei |
| `dark` | 深色科技 | Dark theme with vibrant accents（深色活力） | `#1E1E1E` | Helvetica Neue | Noto Sans SC |
| `corporate` | 商务专业 | Professional navy blue（专业藏蓝） | `#FFFFFF` | Calibri | SimHei |
| `creative` | 创意多彩 | Bright & colorful palette（明亮多彩） | `#FFF8F8` | Montserrat | STKaiti |
| `nature` | 自然清新 | Green & earthy tones（绿色大地色） | `#F1F8E9` | Georgia | STSong |
| `minimal` | 极简黑白 | Clean monochrome minimal（黑白极简） | `#FFFFFF` | Helvetica Light | Noto Sans SC Light |

> **中文字体提示**：模板的次要字体（正文字体）均为中文字体（Microsoft YaHei / Noto Sans SC / SimHei / STKaiti / STSong 等），因此**套用模板后中文文本可正确渲染**，无需手动设置 `font_family`。

## 3. 使用方法

### 方式一：JSON 顶层字段（推荐）

```bash
# 在 unpack 产物的 presentation.json 中设置 template 字段后重建
json2pptx repack out/ -o output.pptx --template dark
```

> `repack` 的 `--template` 会覆盖产物 `presentation.json` 中的 `template` 字段。

### 方式二：产物 JSON 顶层字段

```json
{
  "width": 13.333,
  "height": 7.5,
  "template": "corporate",
  "meta": { "title": "季度汇报" },
  "slides": []
}
```

`repack` 的 `--template` 优先级更高：若两者都指定，CLI 参数会覆盖产物 JSON 中的 `template` 字段。

### 方式三：命令行查看模板列表

```bash
json2pptx templates
```

## 4. 模板与主题的合并逻辑

生成时，模板预设通过以下规则合并到演示文稿中（`src/model/template.rs` + `src/generate/mod.rs`）：

1. 读取 `template` 字段（JSON 或 CLI 参数），按名称查找预设；
2. 预设的 12 色配色写入主题的 `theme.colors`；
3. 预设的标题/正文字体写入 `theme.major_font` / `theme.minor_font`；
4. 预设的背景色写入**第一张**幻灯片的背景（若该幻灯片未指定背景）。

合并发生在生成管线最前端，模板本身不出现在最终 XML 中——它只是主题的"快捷方式"。

> 手动指定 `theme.colors` 中某个色槽时，会覆盖模板同色槽的值（合并顺序为模板 → 用户主题 → 幻灯片背景）。

## 5. 与设计风格系统的关系

模板（6 种）与 [设计风格指南](设计风格指南.md)（12 种风格）是两套互补体系：

| 体系 | 定位 | 使用方式 |
|------|------|---------|
| 模板系统 | 开箱即用的**配色 + 字体**快捷方案 | JSON `template` 字段 / CLI `--template` |
| 设计风格 | 面向 AI 生成的**完整视觉规范**（配色、字号层级、版式规则、图片提示词） | `style` 字段 + AI 技能流程（`skill/SKILL.md`） |

模板更"轻"，适合快速套用；设计风格更"重"，适合追求特定视觉语言的高质量生成。
