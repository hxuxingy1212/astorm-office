# json2pptx 文档中心

**json2pptx** 是一个用 Rust 从零构建的 **JSON ↔ PPTX 双向转换库与命令行工具**。它直接操作 OOXML（Office Open XML）文件格式，**零 PowerPoint / MS Office 运行时依赖**，能够在 JSON 描述与 PowerPoint 演示文稿之间进行完整的双向转换。

受 [slidej](https://github.com/H4pplness/slidej) 架构启发，本项目将 PPTX 内部的 XML 结构抽象为简洁的 JSON 格式，特别适合 **AI 模型直接生成与编辑**（JSON 格式简洁、易读、无冗余）。

---

## 核心特性

| 类别 | 支持情况 |
|------|---------|
| **核心** | JSON → PPTX 生成 与 PPTX → JSON 解析（完整回环） |
| **文本** | 多段落、多 run、项目符号、CJK（含东亚字体 `<a:ea>`）、换行、run 级超链接 |
| **形状** | 86 种形状类型（基础/箭头/流程/标注），填充/线条透明度，adjust 调整值 |
| **线条** | 独立 line 元素：直线/折线/曲线，箭头端点（arrow/dot）、虚线（solid/dashed/dotted） |
| **图片** | 本地路径 / HTTP(S) URL，支持裁剪、超链接、边框 |
| **背景** | 纯色、渐变、图片背景 |
| **表格** | 任意行列，单元格级样式，合并单元格（colspan/rowspan）、自定义列宽 |
| **分组** | 嵌套元素分组，支持旋转 |
| **备注** | 演讲者备注（notes），生成 notesSlide/notesMaster 部件，解析自动还原 |
| **动画** | 24 种类型（入场 / 退场 / 强调 / 路径） |
| **过渡** | 8 种类型，速度与自动翻页控制 |
| **主题** | 自定义配色方案（12 色），标题 / 正文字体 |
| **组件** | 10 种高级组件：progressBar、progressRing、barChart、lineChart、pieChart、ringChart、kpiCard、ratingStars、timeline、processFlow |
| **模板** | 6 种内置模板预设（含中文字体配置） |
| **解包/重建** | `unpack` 按幻灯片拆分为 JSON 中间产物（保留媒体路径），`repack` 重建 PPTX |
| **视图/修改** | `view`（text 文本+媒体 / layout 组件布局）与 `edit`（get/set/add/remove）两层操作，基于 unpack 产物目录（显式、无状态） |
| **Web 预览编辑** | `web/` 网页（Vue3 + Vite + pnpm）上传 PPTX 预览与编辑，`web-server/`（axum）直接调用库 unpack/repack |
| **设计风格** | 12 种设计风格体系（含配色、字体、图片生成提示词） |

**无任何** MS Office 或 PPTX SDK 依赖，OOXML 生成与解析全部由纯 Rust 实现。

## 快速上手

```bash
# 1. 构建
cargo build --release

# 2. 解包为可编辑中间产物
cargo run --release --bin json2pptx -- unpack input.pptx -o out/

# 3. 查看某页文本与媒体
cargo run --release --bin json2pptx -- view input.pptx /slide[1] text

# 4. 从产物重建 PPTX
cargo run --release --bin json2pptx -- repack out/ -o output.pptx

# 5. 列出 6 种内置模板
cargo run --release --bin json2pptx -- templates
```

更详细的上手步骤见 [快速开始](快速开始.md)。

## 项目文件结构

```
json2pptx/
├── Cargo.toml                  # Workspace 根，依赖声明
├── src/
│   ├── lib.rs                  # 库入口：generate / parse / unpack / repack / Error
│   ├── model/                  # JSON 数据模型（serde 反序列化）
│   │   ├── presentation.rs     # Presentation, Meta
│   │   ├── slide.rs            # Slide
│   │   ├── theme.rs            # Theme
│   │   ├── transition.rs       # Transition
│   │   ├── template.rs         # 6 种模板预设
│   │   └── elements/           # Text, Shape, Image, Table, Group, Animation + 7 种组件
│   ├── generate/               # JSON → PPTX 生成管线（含 repack）
│   ├── parse/                  # PPTX → JSON 解析管线（含 unpack）
│   ├── error.rs                # 库级错误类型
│   └── utils/                  # 常量与 XML 辅助
├── cli/                        # CLI 二进制（clap 4）：10 个子命令（unpack/repack/view/edit/render/query/validate/dump 等）
├── web/                        # Web 前端（Vue3 + Vite + pnpm）：PPTX 预览与编辑
├── web-server/                 # Web 后端（Rust axum）：upload/unpack/repack API
├── examples/                   # 示例程序（simple / comprehensive / generate_templates）
├── tests/                      # 39 个集成测试（回环 / unpack-repack / CLI）
├── skill/                      # AI 技能包（SKILL.md + references/）
└── docs/                       # 本目录：完整中文文档
```
