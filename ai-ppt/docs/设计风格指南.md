# 设计风格指南

本文档定义 `json2pptx` 的 **12 种核心设计风格**，内容整合自 10 个开源 PPT 项目：

- AAAAAAAJ/slides（19 种风格）
- oh-my-ppt / arcsin1（70+ 种风格）
- ppt-from-anything / Benioh（4 种结构化风格模板）
- auto-ppt-engine / lijunliu-gh（6 种主题）
- slides-ai-plugin / proyecto26（12 种预设）
- ppt-master（咨询/MBB）
- NanoBanana-PPT-Skills / op7418
- GordenPPTSkill（17 套中文模板）
- banana-PPT / zhangzhengrant
- powerpoint-skill / Noi1r（5 套学术主题）

> **使用说明**：
> - 每种风格包含"风格描述提示词"（可直接作为 AI 演示生成的风格指令）与"图片生成提示词"（英文原文，可直接用于 DALL·E、Midjourney、Stable Diffusion 等主流 AI 图像生成模型；表格中附中文翻译）。
> - 风格可通过 JSON 顶层 `style` 字段引用（`"style": "business-professional"`），并在 AI 生成流程中结合 `skill/SKILL.md` 使用。

## 1. 商务专业（Business Professional）

**源自**：auto-ppt-engine（business-clean, corporate-blue）、oh-my-ppt（极简白）、slides-ai-plugin

**风格描述提示词**（英文原文，可直接作为 AI 生成指令）：

```
Professional clean presentation slide, white/light gray background,
structured layout with clear visual hierarchy,
bold title at top left, subtitle below, body content in bottom 2/3 area,
corporate color palette: navy blue #1A365D, steel blue #4472C4,
medium blue #5B9BD5, light blue #BDD7EE, accent orange #ED7D31,
clean sans-serif typography, generous margins, data charts with consistent styling,
footer with page number and company logo,
Professional business presentation design, 16:9
```

> 中文概要：白色/浅灰背景，清晰的视觉层级；左上角粗体标题、下方副标题、下方 2/3 区域为正文；企业配色（藏蓝 #1A365D、钢蓝 #4472C4、中蓝 #5B9BD5、浅蓝 #BDD7EE、橙色强调 #ED7D31）；干净的无衬线字体，宽松边距，统一风格的数据图表，页脚含页码与公司 Logo。

**配色**：

| 角色 | 色值 | 用途 |

| 次要色 | `4472C4` | 强调形状、图表序列 |
| 浅色 | `BDD7EE` | 表头、高亮 |
| 强调色 | `ED7D31` | 行动号召、重点元素 |
| 背景 | `F2F2F2` | 幻灯片背景 |
| 文字 | `333333` | 正文 |

**字体**：标题 `Calibri Light`，正文 `Calibri`
**字号层级**：标题 40pt、副标题 24pt、正文 16pt、注释 12pt
**版式规则**：顶部标题栏 + 下方内容区，标准卡片布局，数据图表居中

## 风格预设 JSON

每种风格可以作为 JSON 预设引用（`style` 字段 + 主题 + 设计规则）：

```json
{
  "style": "business-professional",
  "theme": {
    "colors": {
      "accent1": "1A365D",
      "accent2": "4472C4",
      "accent3": "5B9BD5",
      "accent4": "BDD7EE",
      "accent5": "ED7D31",
      "dk1": "333333",
      "dk2": "1A1A1A",
      "lt1": "FFFFFF",
      "lt2": "F2F2F2"
    },
    "major_font": "Calibri Light",
    "minor_font": "Calibri"
  },
  "design_rules": {
    "title_size": 40,
    "subtitle_size": 24,
    "body_size": 16,
    "caption_size": 12,
    "whitespace_ratio": 0.25,
    "corner_radius": 0.15,
    "max_bullets": 6,
    "max_words_per_slide": 60
  }
}
```

`design_rules` 各字段含义：

| 字段 | 含义 |
|------|------|
| `title_size` | 标题字号（pt） |
| `subtitle_size` | 副标题字号（pt） |
| `body_size` | 正文字号（pt） |
| `caption_size` | 注释字号（pt） |
| `whitespace_ratio` | 留白比例（0–1） |
| `corner_radius` | 圆角半径（英寸） |
| `max_bullets` | 单页最多条目数 |
| `max_words_per_slide` | 单页最多字数 |

## 通用设计原则

以下原则综合自上述全部项目，适用于所有风格。

### 1. 内容层级

| 层级 | 字号 | 用途 |
|------|------|------|
| 标题 | 36–54pt | 每页一个清晰标题 |
| 副标题 | 20–28pt | 补充上下文 |
| 正文 | 12–18pt | 主要内容 |
| 注释 | 10–12pt | 引用、来源、脚注 |

### 2. 色彩策略

- 全篇一致使用主题色 → JSON 的 `theme.colors`
- 保证 WCAG AA 对比度（正文 4.5:1）
- **整个演示一套强调色**（不是每页一套）
- 暗色页：白字深底；亮色页：深字浅底

### 3. 版式规则

- **16:9 画布**：13.333 × 7.5 英寸
- **边距**：四周至少 0.5 英寸
- **留白**：至少占页面面积的 15–25%
- **条目上限**：单页不超过 6 条
- **最小字号**：投影演示 14pt，讲义 12pt

### 4. 视觉语言

- **形状**：现代 UI 用圆角矩形（roundRect）；专业/商务用直角矩形（rect）
- **阴影**：克制使用，方向一致（通常 135°、右下）
- **渐变**：微妙且有用（不做纯装饰）
- **动画**：内容页只用入场动画（flyIn/fadeIn），不用退场/强调动画
- **过渡**：fade 或 push 保证流畅，避免 random

### 5. 字体搭配

| 字体组合 | 风格 | 适用场景 |
|----------|------|---------|
| Calibri Light + Calibri | 无衬线 | 默认商务 |
| Inter + Noto Sans SC | 无衬线 | 现代科技 / 中文 |
| Helvetica + Noto Sans JP | 无衬线 | 瑞士 / 日式 |
| Garamond + Calibri | 衬线 + 无衬线 | 暗黑高级 |
| Times New Roman + Arial | 衬线 + 无衬线 | 学术 |
| Playfair Display + Inter | 展示体 + 无衬线 | 奢华 |

### 6. 组件使用指南

| 组件 | 使用建议 |
|------|---------|
| `kpi_card` | 每页最多 3 个，放顶部一行 |
| `bar_chart` | 每页 1 个，放中部区域 |
| `timeline` | 页面下方 1/3，4–6 个节点 |
| `process_flow` | 4–5 个步骤，页面中带 |
| `progress_bar` | 顶部或底部边缘，低调 |
| `progress_ring` | 侧边栏，辅助数据 |
| `rating_stars` | 仅产品评测类页面 |

## 风格选择指南

选择风格前先问自己 3 个问题：

1. **受众是谁？**（高管 → 咨询级；投资人 → 极简主义；同行 → 科技赛博）
2. **主题是什么？**（数据报告 → 商务专业；创意 → 瑞士/包豪斯；学术 → 学术论文）
3. **想要什么感觉？**（高级 → 暗黑高级；现代 → 毛玻璃；文化 → 日式简约）

| 如果你想要…… | 选择这个风格 |
|----------------|-------------|
| "专业汇报" | 商务专业 |
| "顶级咨询感" | 咨询级（MBB） |
| "高级感" | 暗黑高级 |
| "科技感" | 科技赛博 |
| "论文答辩" | 学术论文 |
| "产品发布" | 极简主义 或 便当盒网格 |
| "创意提案" | 瑞士国际主义 或 包豪斯 |
| "品牌故事" | 大图叙事 |
| "文化调性" | 日式简约 |
| "现代 AI" | 毛玻璃拟态 |
